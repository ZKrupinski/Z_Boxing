## 제한사항
- GitHub Pages 실제 공개 배포 여부는 위 모의 테스트와 별도임.
- 60fps 장시간/모바일 실기 성능 테스트는 미수행.
- 그로기 → 다운 → 기상 전체 상태 전이에 대한 정식 회귀 테스트는 추가 필요.
- KO 사망 플래시, 넉백, 로프 경계 충돌은 추가 수동 플레이 QA 필요.
- 예전 버전은 보존 목적이며 최신 기준 버그 수정은 반드시 `index.html`부터 반영.

## 테스트 우선순위
1. 실제 GitHub Pages 배포 후 PC/모바일 로딩
2. KO 플래시 100회 반복, 초기화 상태/재대전 확인
3. 넉백 강도별 거리 변화 및 로프 경계 클리핑
4. 전용 다운·기상 스프라이트 크기/발 기준/프레임 겹침
5. 저사양 모바일에서 전투 지속 5분 이상 FPS 측정
