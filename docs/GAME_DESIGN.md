# RING THEORY — 게임 기획서 (2026-11-17)

## 1. 한 줄 소개
거리와 균형, 수싸움의 재미를 직접 조작하는 **2D 실시간 복싱 대전 게임**. 플랫폼은 모바일 가로 16:9, PC 웹 키보드 대응. 게임은 자동 전투가 아니라 매 순간 선수의 공격·가드·이동을 사용자가 직접 결정한다.

## 2. 디자인 원칙
1. **거리의 의미:** 공격마다 유리한 거리를 다르게 하여 단순 연타를 방지한다.
2. **공정한 교환:** 빠르고 안전한 공격과 느리고 강한 공격에 명확한 리스크/리턴이 있다.
3. **실제 복싱다운 리듬:** 전진·후퇴, 스텝, 잽 견제, 카운터, 큰 펀치 이후 회수를 핵심 행동으로 구성한다.
4. **입력의 신뢰성:** 키 씹힘 방지, 인풋 버퍼, 확정된 액티브 프레임, 공격 도중 가드 전환 규칙.
5. **읽히는 동작:** 그래픽 효과보다 리드핸드/뒷손, 체중 중심, 허리 회전, 팔 회수, 무릎 붕괴가 우선한다.
6. **모바일 우선:** 왼쪽 다이내믹 아날로그 스틱, 오른쪽 잽·훅·어퍼·가드 4개 버튼.

## 3. 공격 상성과 거리
| 기술 | 주 역할 | 이점 | 약점 |
|---|---|---|---|
| 잽(Jab) | 원거리 견제/빠른 확인 | 짧은 선딜과 후딜, 긴 리치 | 가드 중인 상대에게 피해 없음, 근거리 훅에 취약 |
| 훅(Hook) | 중거리 압박 | 누적 가드 손상 및 브레이크 | 초근접 어퍼컷 카운터, 빗나가면 밸런스 손실 |
| 어퍼컷(Uppercut) | 초근접 결정타 | 가드 관통 직접 피해 | 상대가 거리를 벌려 잽/훅을 사용하면 취약 |
| 가드(Guard) | 피해 감소/방어 | 잽 봉쇄, 훅 방어 | 연속 훅으로 가드 붕괴, 어퍼컷 관통 |

실거리(px)와 리치 범위는 초기 프로토타입 기준이며, 최종적으로 애니메이션의 손끝과 판정 일치도를 보며 보정한다. **장거리에서 어퍼컷이 닿거나 초근접 잽이 무조건 강한 설계는 지양한다.**

## 4. 밸런스
밸런스는 HP/스태미나와 별도 자원. 큰 공격이 빗나가면 큰 손실, 이동 중 점진적 회복. 밸런스가 무너지면 그로기 또는 다운이 발생해 일시 행동 제한. 다운 후 자동 기상은 프로토타입 규칙이며, 향후 카운트/판정/기상 성공 여부 등 설계 가능.

## 5. 액션 플로우
입력 감지 → 공격 선택 → Startup → Active → 적중/가드/헛스윙 → Recovery → 가능한 캔슬/가드/풋워크 → 다음 행동.

## 6. 손맛
- 일반 펀치: 2~3F 히트스톱과 작은 임팩트
- 강타/카운터: 더 강한 방향성 흔들림·넉백·카운터 반응
- KO: 짧은 실루엣 강조 → 플래시 종료 → 실제 쓰러짐 스프라이트
- 피격 강도별 넉백: 잽 < 훅 < 어퍼, 강타·카운터 추가 보정
- 감쇠/복귀가 자연스럽고 화면 조작 입력을 가리지 않아야 한다.

## 7. 화면/조작
- PC: WASD/방향키 이동, J/K/L 펀치, Space 가드, B 박스 디버그, P 일시정지, R 재시작
- 모바일: 왼쪽 가상 스틱, 오른쪽 잽/훅/어퍼/가드
- 선수들의 기준선은 컨트롤 영역과 겹치지 않게 유지하고, 두 선수 간 간격에 따라 카메라의 줌/구도를 발전시킨다.
- 방해 요소인 심판/관중은 배경화·감광해 시선을 두 선수에 유지한다.

## 8. MVP 완료 기준 (검증 필요)
- 모든 펀치에 일관된 frame-data/박스 판정
- 키보드·모바일 터치 입력이 초당 60회 업데이트에서 누락 없이 작동
- 다운·그로기·기상 각 동작 프레임의 발 위치·충돌·잔상 정합성
- KO 후 플래시 완전 종료, 빈 프레임/깜빡임 없음
- 60fps 근접/원거리, 장시간 반복 시 급격한 성능 하락 없음
- AI가 거리 이점과 방어를 활용하는 것처럼 보이도록 개선

## 9. 제품 방향
단일 라운드 프로토타입 → 완성도 높은 수동 조작 대전 → 선수/스탠스/거리 감각 차별화 → 라운드·판정·카운트·피드백 고도화.
