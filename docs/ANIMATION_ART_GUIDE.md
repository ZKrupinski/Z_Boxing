# 애니메이션·아트 기준서

## 화풍
- 반실사 2D 셀/페인터리 느낌, 근육·골격·장비의 입체감
- 선수 실루엣·펀치 방향·거리 판정의 가독성을 우선
- 캐릭터 디자인과 얼굴, 장갑, 트렁크 색 구분 유지
- 비트맵/PNG 기반. 밝은 외곽 잔여 픽셀과 검은 배경 잔상 제거

## 반드시 별도 원화로 그릴 동작
1. 잽: 방어 → 리드핸드 직선 펀치 → 완전 뻗음 → 빠른 팔 회수
2. 훅: 허리·골반 트위스트 → 디딤발 피벗 → 어깨/주먹 원호 → 회수 → 스탠스
3. 어퍼컷: 무릎·상체 압축 → 중심 상승 → 턱 향한 주먹 → 가드 복귀
4. 풋워크: 전진·후퇴·좌우 이동에서 발 순서 명확히; 뒷발 끌기만 반복하지 않음
5. 피격: 가벼운 / 중간 / 강한 충격에 따라 상체 방향·무게중심 구별
6. 그로기: 균형 상실 → 비틀거림 → 무릎 굽힘 → 회복
7. 다운: 충격 → 중심 붕괴 → 무릎 꺾임 → 몸이 바닥으로 내려감 → 착지
8. 기상: 바닥 지탱 → 한쪽 무릎 → 중심 이동 → 일어남 → 가드
9. KO: 기상하지 않고 최종 자세 유지

## 프레임 제작 규칙
- 동일 인물 체형/의상/얼굴·어깨·주먹 크기 고정
- 각 프레임이 겹치지 않도록 일정 셀 여백 유지
- 투명 PNG 알파 가장자리 깨끗하게
- 발/그림자 바닥 기준점, 캐릭터 무게중심 고정
- 각 동작을 별도 sprite atlas/row로 분류
- 본게임에선 단순 scale/rotate만으로 다운을 대체하지 않음
- 기능별 프레임 길이는 고정 60fps 로직에 맞춰 수정 가능

## 제작/검수 절차
1. 핵심 자세 원화 검수
2. 프레임 분리·여백·알파 QA
3. 리드/리커버리 각 동작의 가독성 확인
4. 액티브 프레임과 실제 손의 접점 확인
5. 다운에서 로프·바닥·피격 방향·위치 확인
6. 모바일 16:9 실제 플레이 화면에서 검수

현재 리소스는 모두 프로토타입으로, 해상도·프레임 일관성·손목/어깨/발 동세의 보완 여지가 있다.
