## 2026-11-17 추가 개선
- 게임 실행 HTML은 루트 `index.html` 하나로 통일하고 `versions/` 보관본 삭제 (필요 시 Git 기록 확인).
- 잽/훅/어퍼컷, 걷기·가드·대기, 피격·그로기·다운·기상의 기존 PNG 원화 사이에 보간 프레임 추가.
- 60FPS 프레임 데이터와 히트 판정 시점은 유지. 새로운 손그림 원화 프레임을 제작한 것은 아님.

- 링 전체 70px 하향: 바닥·로프·기둥·선수·전투 이펙트 및 판정 표시의 화면상 위치를 함께 이동하고 상단 HUD와 입력 조작은 고정. 월드 좌표와 타격 프레임은 변경 없음.

- 전투 중 선수 머리 위에 표시되는 데미지·BLOCK·COUNTER·DOWN·DIZZY·WHIFF 등 팝업 텍스트를 비활성화, 이펙트·타격 리액션은 유지.
- 양쪽 복서 최대 체력 100 → 200 HP, 체력바 비율 계산 보정. 라운드 제한 시간 90 → 180초로 변경. CPU의 저체력 공격 빈도 전환 기준도 비례 조정.
