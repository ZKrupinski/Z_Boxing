# Z_Boxing — RING THEORY

복싱의 **거리 조절, 수 싸움, 공격 상성, 밸런스**를 조작으로 구현하는 2D 복싱 액션 게임입니다.

> **개발 상태:** 플레이 가능한 HTML 프로토타입 (루트 `index.html`을 수시 갱신). PC 키보드 / 모바일 가로 터치 조작 지원.

## 게임 조작
| 키 | 기능 |
|---|---|
| WASD / 방향키 | 복싱 풋워크 및 이동 |
| J | 잽 |
| K | 훅 |
| L | 어퍼컷 |
| Space | 가드 |
| B | 히트박스·허트박스·푸시박스 확인 |
| P | 일시정지 |
| R | 라운드 재시작 |
| 1 / 2 | 그로기 / 다운 동작 시연 (V5 실험 기능) |

모바일은 화면 왼쪽 가상 스틱과 오른쪽 펀치·가드 버튼을 사용합니다.

## 핵심 규칙
- 잽: 긴 거리 견제, 가드에 약함
- 훅: 중거리 압박, 누적 가드 브레이크
- 어퍼컷: 인파이팅, 가드 관통
- 빗나간 큰 공격: 밸런스 손실, 반격 위험
- 풋워크: 밸런스 회복과 거리 조절
- 선딜레이(Startup) / 유효판정(Active) / 후딜레이(Recovery), 인풋 버퍼, 단일 히트 판정
- 그로기, 다운·기상, KO, 공격별 넉백과 히트스톱
- 기본 원화와 충돌 판정 프레임은 보존하면서 공격·이동·피격·다운 애니메이션의 중간 프레임 보간

## 저장소 운용
- `main`: 최신 플레이 가능 기준
- `index.html`: 루트에서 직접 갱신하는 유일한 게임 실행 HTML (별도 버전 폴더 없음)
- `docs/`: 기획 의도, 기술 규칙, 아트 기준, QA 이슈
- `assets/`: 재사용 가능한 원화·스프라이트 리소스

**주의:** 현재까지의 빌드는 프로토타입이며 모든 애니메이션과 판정의 최종 품질을 보증하지 않습니다. 향후 수정은 실제 게임플레이 테스트와 QA를 거쳐 루트 `index.html`에 직접 반영합니다.
